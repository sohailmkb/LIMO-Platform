# Limo Platform

Multi-operator chauffeur, limo and shuttle platform for the US, Canada, UK and EU.

- `docs/ARCHITECTURE.md`: design, security, what is verified and what is not
- `docs/SETUP.md`: first run on Supabase
- `docs/lovable/prompt-pack-1.md`: prompts for the operator web
- `supabase/`: migrations and seed
- `apps/mobile/`: Expo app with Driver, Customer and Admin modes
- `packages/shared/`: locale, money and status helpers
- `tests/db/`: database tests (`npm run test:db`)
